# About Me:

Soy Desarrollador Full Stack y Analista de Datos, orientado a la creación de soluciones digitales eficientes y al análisis estratégico de información. Me destaco por ser una persona proactiva y responsable, con capacidad para integrarme rápidamente en equipos de trabajo bajo metodologías ágiles (SCRUM).

Mi enfoque se divide en dos grandes áreas que se complementan:

Análisis y Estrategia: Utilizo el análisis de datos para la toma de decisiones, la identificación de oportunidades de mejora y la proyección de tendencias que aporten valor real a la empresa.

Desarrollo y Calidad: Transformo ideas en conceptos tangibles mediante el desarrollo de software (Stack MERN). Priorizo la calidad del producto final, la arquitectura robusta en el backend y una documentación clara para evitar deuda técnica.
